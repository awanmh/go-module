## 🚀 Panduan Menjalankan Program Go

1. **Memastikan Instalasi Go**:
   ```bash
   go version
   ```
2. **Menjalankan Program Langsung**:
   ```bash
   go run main.go
   ```
3. **Merapikan Format Kode Secara Otomatis**:
   ```bash
   go fmt ./...
   ```
4. **Mengompilasi Berkas Biner Executable**:
   ```bash
   go build main.go
   ```
